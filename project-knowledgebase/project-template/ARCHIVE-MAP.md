# Archive Map

**Purpose:** Index of everything archived out of the live KB — where it came from, where it went, and why. Load this only when you need to go back into the project's history; `DOCUMENT-MAP.md` covers the live material.

Any directory may have an `archive/` subdirectory (`plans/archive/`, `reviews/archive/`, `scratch/archive/`, ...). Archiving moves a file or directory into the `archive/` beside it, keeping its name; every move gets a row here. The table doubles as the undo list: to restore something, move it from **Now at** back to **Was at**.

Rotated-out history from `02-status.md` or `03-decisions.md` goes to `journal/` instead, and gets a row here too.
